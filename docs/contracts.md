## 1. Core Data Contract: Lesson Plan JSON (Gaurang -> Whole Team)

This is the central payload generated by `core/lesson_planner.py`. All downstream media generation (Siddhant), visual classification (Yukta), interaction evaluation, and UI rendering (Harsh) consume this JSON structure.

```json
{
  "title": "Chapter 4: Electricity",
  "level": "beginner",
  "time_minutes": 20,
  "language": "hi",
  "topic_or_chapter": "Electricity Fundamentals",
  "sections": [
    {
      "id": "s1",
      "concept": "Current and Voltage",
      "explanation": "Electric current is the rate of flow of electric charges in a circuit...",
      "example": "Imagine water flowing through a pipe...",
      "visual_type": "diagram",
      "narration_script": "Namaste! Aaj hum electricity ke baare mein samjhenge...",
      "checkpoint_question": {
        "type": "mcq",
        "question": "What unit is electric current measured in?",
        "options": ["Volts", "Amperes", "Ohms", "Watts"],
        "correct": "Amperes"
      }
    }
  ],
  "final_quiz": [
    {
      "id": "q1",
      "question": "State Ohm's Law formula.",
      "options": ["V = I * R", "V = I / R", "I = V * R", "P = V * I"],
      "correct": "V = I * R"
    }
  ]
}
```
